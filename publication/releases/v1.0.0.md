# Climate Change Knowledge Graph 1.0.0

This is the first release of the workflow. It is also the release of the Climate Change Knowledge Graph (CCKG) 1.0.0, the
first in the namespace `https://w3id.org/climate-change-kg/`, as described in the data descriptor
written for Scientific Data.

## The knowledge graph

- **Build:** of 13 November 2026, from commit `fc47aa0`.
- **Size:** about 5.7 million triples (without inferred ones), in 15 named graphs (one for each ontology and for each
  source) plus a named graph with the metadata of the KG.
- **Content:** 2,775 simulations (696 global simulations and 2,079 dynamical downscalings) that use 93 climate models,
  and about 613,000 datasets.
- **Validation:** checked with the SHACL shapes of `shapes/` (51 node shapes, 106 property shapes), with no violation.
- **Archive:** the dump (`kg.nq.gz`, gzipped N-Quads) and its description (`void.ttl`: DCAT, VoID, PROV-O, DQV) are on
  Zenodo, at DOI _to be added_. The files are the same as version 15 of the earlier Figshare record
  ([10.6084/m9.figshare.29066711.v15](https://doi.org/10.6084/m9.figshare.29066711.v15)).
- **Online:**
  - SPARQL endpoint: <https://w3id.org/climate-change-kg/sparql>
  - resources, which dereference: `https://w3id.org/climate-change-kg/data/...`
  - documentation: <https://w3id.org/climate-change-kg>

## What this tag contains

The tag `v1.0.0` is commit `fc47aa0`, which built the KG 1.0.0, plus `CITATION.cff`. The KG can be rebuilt from it
(see the README; `snakemake --cores 4 consolidate validate`). The commit recorded in its metadata is `fc47aa0`.

The later changes on `main` are not in this release. They include the website in `website/`, the references to the
repository under its new name, and the namespace of the shapes (`https://w3id.org/climate-change-kg/shapes/`). Some of
them change the metadata of the KG, so they will come with the next release.

## Earlier snapshots

Before this release, snapshots of the KG were published on Figshare
([10.6084/m9.figshare.29066711](https://doi.org/10.6084/m9.figshare.29066711), versions 1 to 15, from May 2025). Versions 1
to 14 use the former namespace `https://w3id.org/hacid/data/cs/` and count as pre-1.0 releases.
