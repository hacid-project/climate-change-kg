# Climate Change Knowledge Graph (CCKG)

Permanent identifiers of the [Climate Change Knowledge Graph](https://w3id.org/cckg): its resources and named graphs
(`/cckg/data/...`), its SPARQL endpoint (`/cckg/sparql`) and its documentation (anything else).
